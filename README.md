# 🎵 Music Player

A modern and user-friendly music player application built with **Flutter and Dart**.

Music Player is a personal music application designed to provide a simple and enjoyable music listening experience. The goal is to build an application that can access local audio files and provide useful music playback features.

> 🚧 **Project Status:** Under Development

## ✨ Features

### Available / In Progress
- [x] Flutter-based application structure
- [x] Local audio file selection
- [x] Basic music playback
- [x] Play and Pause functionality
- [x] Music duration and playback position

### Planned Features
- [ ] Automatic local music library scanning
- [ ] Playlist management
- [ ] Favorite songs
- [ ] Next and Previous track controls
- [ ] Music search functionality
- [ ] Background audio playback
- [ ] Modern user interface
- [ ] Video and live-stream viewing

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Git

### Installation

1. Clone the repository:

```bash
git clone https://github.com/ronist-hue/Music-Player-.git
```

2. Navigate to the project directory:

```bash
cd Music-Player-
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```
